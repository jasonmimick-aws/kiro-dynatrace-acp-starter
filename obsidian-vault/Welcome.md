# Kiro + Dynatrace Observability Vault

Welcome! This Obsidian vault is pre-configured to use Kiro CLI as an AI agent via ACP (Agent Client Protocol).

## What you can do here

- Ask Kiro to query Dynatrace logs, metrics, and traces in plain English
- Investigate incidents without leaving your notes
- Reference your notes with `@notename` when talking to Kiro
- Export Kiro's responses as Markdown notes

## Try these prompts

- "Show me error logs from the last hour"
- "Are there any open problems in my Dynatrace environment?"
- "Summarize @meeting-notes and pull related Dynatrace alerts"
- "Create a dashboard for my top 5 services by error rate"
